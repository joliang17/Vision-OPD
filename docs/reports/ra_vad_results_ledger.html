4 · 诊断（motivation）

为什么要把对比信息写进 target

一句话：旧设计把 lp_hi−lp_ctrl 只当权重用，但权重最高十分位上 teacher-student KL 仅 0.0007 nats（比 hi-ctrl 差距小 ~1800×）——在给不存在的信号加权；EMA 分解证实早期收益 ~83% 来自自蒸馏正则化本身（纯 EMA 67.79 vs noimg 68.20 vs base 65.78）。→ 对比信息必须进 target 本身，这就是 contrast-sharpened target 的动机。uniform 反转（消融 C）与该诊断自洽。

M1 · "模型忽视视觉证据"定量（intro 数字，07-18 出）

一句话：2B base 在 POPE 上真图换黑图后69.6% 的答案纹丝不动（黑图条件下还能"答对"71.4%——语言先验泄漏实锤；真图 91.0）；VStar 不变率 39.3%（acc 74.9→34.6）。产物：analysis_outputs/m1_probe/{pope,vstar}_2b_base.json（n=500/191，greedy 双条件）。

M2 · privileged-hint 的本征缺陷（S2a 归因，07-18 出）⚠ 07-20 复现测试未通过，见 §2-F 提示框

一句话（07-18 原始分析，⚠ 结论待复核）：answer-hint OPSD 训出的模型在 eval（无 hint）时凭空引用"reference answer"并朝想象答案推理——unfiltered 版 12.6% vs filtered 版 2.9%（4.3×），文本连贯、0 API 失败、judge 无辜。原判断：privileged-hint 训练的 train-test mismatch 本征缺陷，黑图 ctrl 结构性免疫。07-20 更新：S2b 换 seed 复现测试结果 68.44（未崩溃，甚至高于 base），与本节"本征缺陷"的强 claim 矛盾——详见消融 F 表下方独立提示框，结论暂标记 open question，不建议在当前状态下直接引用本节作为 paper 论据。FC4 细曲线（幻觉率随训练步数）素材已训完，eval 待排，可作为独立佐证来源。
