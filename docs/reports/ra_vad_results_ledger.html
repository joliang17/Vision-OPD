D · guarded tilting（β mask 与 EOS 豁免）因果两臂定案 07-19

一句话（升级为全项目最强机制证据）：β mask 判「留」——两臂续训因果实锤：β=0 与 β=0.1 唯一变量为 β，同步续训到 200 步；β=0 在 150–200 区间灾难性全面崩溃（Zoom 单调 41.89→31.01→27.93→23.67；step150 9-bench：MathVista −19.9 / BLINK −10.4 / MMStar −12.5 / Hallu −6.3），β=0.1 对照全程平稳（Zoom 40–42 震荡、9-bench 无系统性下滑）。机制解释闭环：forward-KL mass-covering + EMA 反馈环累积放大无界 log-ratio 的 target 污染，β 把每步漂移限制在 teacher 可信支撑集内。90 步内 β=0 仅 −1.78pp——β 的价值在扩展训练窗口，短程消融看不到。EOS 豁免（X14）接近 no-op，保留为工程默认。

4 · 诊断（motivation）

为什么要把对比信息写进 target

一句话：旧设计把 lp_hi−lp_ctrl 只当权重用，但权重最高十分位上 teacher-student KL 仅 0.0007 nats（比 hi-ctrl 差距小 ~1800×）——在给不存在的信号加权；EMA 分解证实早期收益 ~83% 来自自蒸馏正则化本身（纯 EMA 67.79 vs noimg 68.20 vs base 65.78）。→ 对比信息必须进 target 本身，这就是 contrast-sharpened target 的动机。uniform 反转（消融 C）与该诊断自洽。

M1 · "模型忽视视觉证据"定量（intro 数字，07-18 出）

一句话：2B base 在 POPE 上真图换黑图后69.6% 的答案纹丝不动（黑图条件下还能"答对"71.4%——语言先验泄漏实锤；真图 91.0）；VStar 不变率 39.3%（acc 74.9→34.6）。产物：analysis_outputs/m1_probe/{pope,vstar}_2b_base.json（n=500/191，greedy 双条件）。

M2 · privileged-hint 的本征缺陷（S2a 归因，07-18 出）

一句话：answer-hint OPSD 训出的模型在 eval（无 hint）时凭空引用"reference answer"并朝想象答案推理——unfiltered 版 12.6% vs filtered 版 2.9%（4.3×），文本连贯、0 API 失败、judge 无辜，= privileged-hint 训练的 train-test mismatch 本征缺陷；黑图 ctrl 无信息可依赖、结构性免疫。S2b 换 seed 复现中；FC4 细曲线将给出幻觉率随训练步数的过程曲线。
